# Provenance and redistribution notes

All files in this package are newly added under `contrib/waveshare-esp32-c5-35/`; no vendor CAD archive, drawing, PDF, firmware, or other reference file is redistributed here.

- The Marauder source snapshot is derived from the repository base recorded in `source/SNAPSHOT.md` and follows the repository license.
- The only retained human attribution is the requested public GitHub identity `p-keminer <p-keminer@users.noreply.github.com>` in `source/SNAPSHOT.md`; no local account name or private email address is included.
- The wiring PNG is an original project diagram of the tested pin assignment; manufacturer source documents are not copied into this package.
- The enclosure STLs are original project-specific exports. Editable CAD, manufacturer CAD, reference meshes, fit assemblies, and design-history revisions are not redistributed in this package.
- `enclosure/PARTS.md` links to official manufacturer pages where an exact match could be verified. Clean Amazon ASIN links are retained only for purchased private-label items for which no independent authoritative product page was found.
- The TFT profile identifies the ST7796S display and FT6336U touch controller used by the tested Waveshare module.
- Prebuilt firmware incorporates Marauder and the dependency revisions recorded in `source/dependency-lock.txt`; the respective upstream licenses continue to apply.
- Published application images use compiler prefix maps so embedded source diagnostics contain only neutral relative prefixes, never the builder's username or absolute workstation path.
- `boot_app0.bin`, the bootloader, and partition artifacts come from or are generated by Espressif Arduino core 3.3.5 as recorded in the build manifest; Espressif's applicable license terms continue to apply.
- Product and company names are used only to identify compatible hardware and remain the property of their respective owners.

Public-package hygiene checks confirmed that the package excludes real local COM-port identities, device-specific MAC addresses, local network identifiers, local account names, absolute workstation paths, captures, and unrelated test media. The installer regression fixture uses only synthetic COM41/57/88/99 identifiers.
